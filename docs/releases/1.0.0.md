# 我的伙伴非官方移植版 1.0.0 Release

正式版加载器版本为 **1.0.0**，模组 ID 为 **my_companion**。本次加入正式封面与完整模组信息，功能沿用 0.2.1。

## 平台和安装

| 安装包 | 游戏与依赖 |
| --- | --- |
| `[我的伙伴非官方移植版]my-companion-unofficial-1.0.0-Fabric1.20.1.jar` | Minecraft 1.20.1、Java 17、Fabric Loader 0.16.14 或兼容更新版、Fabric API |
| `[我的伙伴非官方移植版]my-companion-unofficial-1.0.0-NeoForge26.3.jar` | Minecraft 26.3、Java 25、NeoForge 26.3.0.95 |

将匹配平台的安装包放入游戏实例 mods 文件夹；多人服务器与客户端均需安装。升级时移走旧版同模组 JAR，勿同时保留多个版本。源码包仅供开发。

正式包从各工程 build/libs 取得，发布后可放在 GitHub Release 附件中。两种加载器的安装包不能互换；不提供 Fabric 1.20.1 与 NeoForge 26.3 世界之间的直接迁移。

## 功能

- 自动生成每名玩家的专属狐狸“我的伙伴”。
- 自动跟随、远距离安全召回及跨维度处理。
- 直接免疫伤害，包含虚空、创造攻击和 kill 伤害。
- 低头时靠近脚下，主动寻找压力板及已连接绊线。
- 右键控制面板分别开关两项调皮行为，设置按玩家保存。

## 名称、版本与封面

Fabric 使用 name/version/icon，NeoForge 使用 displayName/version/iconFile / bannerFile，JAR Manifest 同时包含 Implementation-Title/Implementation-Version。封面由用户提供，原图未重绘、裁剪、缩放或修改。

加载器版本使用标准 1.0.0，Release 表示正式发布阶段。Fabric 如需在游戏图形界面查看模组列表和图标，可额外安装适用于 1.20.1 的 [Mod Menu](https://modrinth.com/mod/modmenu)；本模组不会强制捆绑它。
