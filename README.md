# 我的伙伴非官方移植版

一个适用于 Minecraft Java 版的非官方移植模组，在游戏中添加一只会自动跟随玩家的狐狸伙伴，并增添了一些功能。


## 功能

- **自动跟随**：伙伴会自动跟随玩家移动。
- **远距离传送**：当伙伴距离玩家过远时，会自动传送至玩家附近。
- **低头跟随**：玩家低头时，伙伴会自动移动到玩家脚下。
- **红石装置交互**：伙伴可以自动触发附近的绊线、压力板等装置。
- **功能设置**：右键点击伙伴可打开设置面板，分别开启或关闭低头跟随与自动触发装置的功能。

## 支持的版本

目前支持以下 Minecraft Java 版版本：

| Minecraft 版本 | 模组加载器 |
|---|---|
| 1.20.1 | Fabric |
| 26.3 | NeoForge |

后续计划逐步适配更多 Minecraft 版本及模组加载器。

远期目标是尽可能实现跨版本支持。

*至于全版本支持……那恐怕是很久以后的事情了。*

## 安装与使用

1. 安装与游戏版本对应的 Fabric 或 NeoForge 模组加载器。
2. 下载适用于当前 Minecraft 版本的模组 JAR 文件。
3. 将 JAR 文件放入游戏目录的 `mods` 文件夹。
4. 启动游戏，进入世界即可体验狐狸伙伴。

请确保下载的模组文件与 Minecraft 版本、模组加载器相匹配。
